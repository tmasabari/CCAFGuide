Explain the file `$ARGUMENTS` in the context of this repository.

Cover:
- purpose and responsibilities;
- how the implementation works;
- important dependencies and design choices;
- failure modes and edge cases;
- relevant tests and obvious test gaps.

Use only repository evidence. Say when information is unavailable instead of guessing.
